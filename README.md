# .github

Default community files for the `usespotlightai` organization: issue forms, the pull request template, `SECURITY.md` and `CONTRIBUTING.md`. A repository that has its own copy of a file uses its own copy.

`labels/` defines the labels. `scripts/sync-labels.sh` creates or updates them in every repository. `all.tsv` goes to every repository, and `<repository>.tsv` goes only to that repository.
